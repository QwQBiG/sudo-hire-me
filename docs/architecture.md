# 架构与运行边界

项目采用 React、TypeScript 和 Vite，输出可以独立部署的静态文件。课程内容、页面呈现和代码执行分别维护，不需要应用服务器或远程数据库。

## 内容流

```text
content/lessons/*.md
        |
        v
scripts/build-content.mjs
        |
        +--> .generated/lessons.json --> 轻量目录与搜索
        |
        +--> public/data/*.json --> 进入课程时按需加载
        |
        +--> public/lessons/*.md --> Markdown 下载
```

Markdown 的 YAML frontmatter 保存课程元数据。解析器通过 schema 验证字段，检查文件名与 slug、一致的课程顺序以及先修引用；正文由 remark 解析，按二级标题组织为课程小节。

面试回答、选择题及其解释、实验代码均从正文提取，避免在组件里维护另一份内容。`src/types.ts` 定义页面使用的数据类型；`lab` 字段只选择内置实验，不能引入任意组件代码。

课程的“逐步推演”小节由 AST 按三级标题提取，保留 Markdown 表格和代码，用于原理阅读。目录 JSON 不包含正文；进入课程后才加载相应数据。构建检查先修关系中的未知引用和循环，测试检查先修课程排在当前课程之前。

“多语言示例”小节按语言标题提取并逐个验证代码围栏；页面只显示当前选中的语言，偏好保存在本机。`LessonView` 随课程页按需加载，首页不必先下载 Markdown 渲染器。

交互实验由 `src/components/Lab.tsx` 按 `lab` 标识按需加载。基础实验分布于 `src/labs/foundations/`、`src/labs/systems/`、`src/labs/practice/`。`workbench` 课程通过 `src/domain/workbench-catalog.mjs` 显式映射到 `src/labs/workbenches/` 中的机制实验，再按需加载对应组件。构建时拒绝没有映射的课程，不提供文字翻页兜底。`Experiment` 与 `Bench` 统一标题、重置与反馈，实验内部使用对象图、栈、依赖网格、报文、版本链等适合概念的布局。

可变输入与状态转换的教学模型位于 `src/domain/` 的对应模块，使用纯函数测试。模型只处理已声明的有限场景，不实现完整 CPU、操作系统、网络协议栈或数据库引擎。Markdown 保留概念、例题和模型假设，即使不打开网页也能独立理解；修改模型时应同步检查相应正文。

`Lab` 为实验提供共享的视觉反馈：`useLabMotion` 只在操作后动画显示变化的读数，并通过稳定的 `data-token-id` 连接任务在不同位置的移动。动画不延迟状态更新，课程切换与卸载会清理观察器和动画；系统及本机的减少动效偏好同时生效。`SignalRoute` 表达报文、校验和返回路径，`scenes.css` 按实验结构设置舞台，不改动教学模型。

`npm run content`、`npm run check` 和 Vite 构建均可能重新生成内容。生成目录不是编辑入口；课程变更须回到 `content/lessons/`。

## 页面与资源

hash 路由让课程地址的片段部分由前端解释，静态服务器仍然加载站点入口。Vite 的 `base` 为 `/sudo-hire-me/`。静态资源、课程下载和 Wasm 地址必须保留该前缀，不使用假定部署在域名根目录的路径。

Markdown 渲染不执行其中的代码，也不将原始 HTML 作为页面组件。代码只有通过明确的运行操作才进入运行器；链接与运行输出不能作为可执行标记插入页面。

课程代码块使用按需加载的 lowlight 和显式注册的语言语法生成文本节点及高亮节点，由 React 渲染，不注入 HTML 字符串。未知语言和超过 30000 字符的代码按原文显示。代码块支持行号、换行、折叠和复制，编辑型运行器仍独立维护。

`LessonReading` 用可收起的目录、当前小节定位和节间跳转组织长文；定位条表示阅读位置，不代表已理解或已通过。口述草稿与课程笔记共用已有 `note` 字段，不另设进度格式；参考短答来自 Markdown。复习页只显示已有阅读、练习、收藏或笔记记录的课程。

只读代码块的横向滚动由单一容器承担，溢出时提供方向按钮；动态测量和事件监听在折叠、切换与卸载时清理。运行器结果区显示总用时（包括引擎加载）和实际输出数量；编辑代码后保留上次结果，并明确标记其归属。视觉反馈不能延迟状态提交，也不能用动画完成替代模型完成。

配色与布局样式分别位于 `src/styles/`；步骤切换、页面进入和状态变化使用 CSS 过渡。所有动效都遵守系统减少动态效果设置和站点的减少动效开关。筛选只影响目录，不修改课程顺序或已有学习记录。

## 实验形式

| 类型          | 执行内容                             | 边界                                       |
| ------------- | ------------------------------------ | ------------------------------------------ |
| 教学模拟      | 受约束输入、资源操作与可观察状态转换 | 不代表真实硬件、协议栈或操作系统的执行轨迹 |
| Markdown 例题 | 阅读具体案例、计算过程与代码示例     | 属于原理阅读，不代替实验或代码运行         |
| JavaScript    | 用户编辑后的 JavaScript              | 浏览器 Worker 环境，不提供 DOM 或 Node.js  |
| SQL           | sql.js 中的 SQLite 查询              | 内存数据库，不代表远程数据库服务器         |

Rust 所有权实验属于教学演示，诊断文本是参考材料。不能将其显示为用户代码的真实编译结果。

## JavaScript 运行器

运行器使用受信任的 iframe 控制器创建 Blob Worker，用户代码只在 Worker 中执行。维护时必须保留以下边界：

- iframe 仅允许脚本，不启用 `allow-same-origin`、弹窗或顶层导航。
- CSP 默认拒绝资源，仅为控制器脚本和 Blob Worker 开放必要能力，禁止网络连接。
- 用户代码通过消息传入，不拼接到 iframe HTML，不在页面线程执行。
- 父页校验 iframe 消息来源、当前会话和运行标识；`origin` 为 `null` 不构成可信身份。
- 停止、超时、重新运行和组件卸载都要终止旧 Worker，忽略旧运行的迟到消息。
- 限制输出数量与大小，输出按普通文本显示；错误与超时不得伪装成成功结果。

普通 URL Worker 通常不继承创建页面的 CSP，Blob Worker 存在继承规则。修改 Worker 的创建方式时必须重新验证网络与存储边界。Worker 可以隔离执行线程，但不能提供严格的内存配额或绝对防止浏览器资源耗尽。[MDN：Worker 与 CSP](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers#content_security_policy)

## SQL 运行器

sql.js 和 Wasm 随站点提供，查询在专用 Worker 内执行。每次运行都创建初始示例数据库，不连接生产服务；前次执行的修改不会保留。结果最多显示 100 行、30 列，单元格文本最多 1000 字符，总文本预算为 30000 字符；超出时显示截断提示。

维护时需保留超时与停止操作，限制查询输出，并在销毁时释放数据库和预编译语句。终止执行线程后，数据库状态可能丢失，应重建实例和示例数据。不得把用户输入注册为 JavaScript 函数。[sql.js 文档](https://github.com/sql-js/sql.js)

首次加载引擎最多等待 60 秒。Worker 发出就绪消息后才启动 5 秒的查询执行计时，不能将网络下载时间计入查询预算；加载期间也可以停止。

## 进度存储

`src/domain/progress.mjs` 定义版本为 `1` 的数据格式，包含课程阅读状态、练习通过状态、尝试次数、书签、笔记和减少动画设置。

解析函数检查未知字段、课程 ID、状态类型和长度。输入字符串上限为 500000 个 UTF-16 代码单元，导入文件上限为 2000000 字节，单条笔记上限为 5000 个 UTF-16 代码单元。容量测试覆盖 60 课写满中文笔记后的往返导入。导入须先完整校验，再更新当前记录；失败时应保留原数据。

课程顺序可以按先修关系调整，但已有 slug 不变。增加课程不更改进度版本，旧课程的笔记、收藏和练习记录仍按相同 slug 读取。

本地持久化不意味着跨设备同步。浏览器清理、隐私模式、存储配额或禁用存储都可能影响保存。结构变化需要明确迁移或拒绝旧格式，不能无提示重置已有进度。

## 验证重点

各类展示和操作遵守[课程展示与交互约定](interaction-contract.md)，新增实验须同时维护模型边界、错误反馈与恢复路径。

- 课程解析：正常课程、缺失必填字段、重复标识和无效先修引用。
- 运行器：正常输出、语法错误、停止、超时、连续运行及旧消息。
- 状态：进度导出导入、非法文件、不可用存储和未知版本。
- 页面：桌面与移动端阅读、键盘操作、代码与表格滚动、减少动画设置。
- 部署：构建后的资源前缀、课程直达地址、Wasm 加载与控制台错误。

代码检查、浏览器行为验证和线上部署验证是不同结果，应分别记录。构建完成不代表站点已经部署。
