# sudo-hire-me

从概念、例题和实验开始，逐步理解计算机基础与面试问题。

课程正文使用 Markdown 维护，网站提供可操作的知识实验、代码与查询运行、选择题和本地学习记录。读完一课后，再用简短回答检验自己是否能讲清概念、过程和适用条件。

站点入口：[iqwqi.win/sudo-hire-me](https://iqwqi.win/sudo-hire-me/)。

默认进入学习首页，可继续最近未通过的课程、搜索知识点或按主题探索。课程目录支持主题与状态筛选，复习手册集中显示收藏、笔记和待巩固记录；侧栏和课内学习工具可分别收起。

## 课程范围

目前包含 **233 节课程：226 节核心课程和 7 节 JavaScript 选修**，按先修关系逐步展开。以面试需要的理解与表达为重点，不是完整考研课程，也不是按题目堆叠的面试合集。[课程路线图](docs/curriculum-roadmap.md)说明范围和质量要求。

| 主题 | 主要内容 | 实验形式 |
| --- | --- | --- |
| 编程基础与面向对象（29 课） | 程序、函数、短路、内存、指针、类与对象、封装、继承、多态 | 地址、生命周期与求值路径实验 |
| 计算机基础（18 课） | 数制、浮点、CPU、缓存、流水线、存储层次与设备 I/O | 位运算、缓存映射、分支预测与 DMA 时序 |
| 数据结构与算法（38 课） | 查找、排序、树、图、字符串、LRU、单调栈与循环证明 | 缓存淘汰对照、柱图栈、图路径和状态表 |
| 操作系统（26 课） | 进线程、系统调用、调度、同步、映射、权限、文件与 I/O | 父子退出、权限位图、映射与写回 |
| 计算机网络（25 课） | 分层、TCP/UDP、DNS、HTTP、TLS、认证授权与密码学基础 | 报文、窗口、权限门与 Web Crypto 运算 |
| 数据库（25 课） | SQL、NULL 统计、参数绑定、索引、事务、隔离与查询计划 | SQLite 查询与真实参数绑定对照 |
| 并发与系统设计（15 课） | CAS、线程池、队列、超时、重试、幂等、限流与隔离 | 原子更新、有界队列与令牌桶 |
| 工程实践（15 课） | Git、测试、构建、持续集成、观测、发布与故障处置 | Git 状态、边界用例和日志证据 |
| 语言机制（28 课） | C、C++、Python 3、Rust、Zig、Java、Kotlin 的语言特有规则 | const 权限、引用计数、迭代器、GIL、comptime 与运行时模型 |
| 项目与面试表达（7 课） | 项目讲解、个人贡献、技术取舍和追问应对 | 证据选择与可核对的表达 |
| JavaScript 选修（7 课） | 值、闭包、原型链、事件循环和异步 | 浏览器隔离环境中的代码运行 |

JavaScript 在浏览器的隔离 Worker 中运行，不提供页面 DOM 或 Node.js 环境。SQL 使用浏览器内的 SQLite，与其他数据库的语法和行为可能不同。Rust 示例不连接编译器，显示的诊断是教学参考。

每课提供面试短答、从零讲解、具体例子、常见误区和自测。专有名词首次解释时附英文全称；当前正文以中文为主。部分通用算法课提供 C、C++、Python 3、Rust、Zig、Java、Kotlin 的并列示例。网页支持从零开始的连续路线、分组侧栏、主题筛选、先修课跳转和课内目录；代码支持高亮、换行、折叠和复制。

## 本地开发

需要 Node.js 22.19.0 或更新的兼容版本，以及 npm。

```powershell
npm install
npm run dev
```

按照终端输出的地址打开 `/sudo-hire-me/`。默认端口可用时，地址为 `http://127.0.0.1:5173/sudo-hire-me/`。

```powershell
npm run check
npm test
npm run build
npm run preview
```

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务，生成课程数据 |
| `npm run content` | 校验 Markdown 并更新生成内容 |
| `npm run check` | 校验和生成课程内容，再检查 TypeScript |
| `npm test` | 运行测试目录中的 Node.js 测试 |
| `npm run build` | 检查项目并生成 `dist/` |
| `npm run preview` | 本地预览构建产物 |

检查命令会更新生成目录，不是只读检查。开发服务监听课程的添加、修改与删除；内容格式错误会在页面提示。

## 项目结构

```text
content/lessons/       课程 Markdown，唯一内容源
scripts/              内容解析与生成
src/                  页面、实验组件和运行器
src/domain/           搜索、进度等独立逻辑
public/               静态资源
.generated/           构建生成的课程数据
public/lessons/        构建复制的 Markdown
public/data/           按课程拆分的正文数据
dist/                 生产构建产物
docs/                 维护和内容编写说明
```

不要直接编辑 `.generated/`、`public/lessons/`、`public/data/` 或 `dist/` 中的课程副本。

## 学习记录

阅读状态、练习结果、书签和笔记保存在当前浏览器中，不上传服务器。清除站点数据、更换浏览器或使用另一设备不会自动保留记录；需要通过进度导出和导入转移。

导入文件须通过格式和课程 ID 校验。进度仅用于个人复习，不作为可靠的考试成绩或身份凭据。
