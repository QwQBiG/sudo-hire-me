# 前缀和与静态区间查询

## 为什么提前做一点工作

数组 `a=[2,-1,3,4,-2]`，若多次问“下标 1 到 3 的和是多少”，每次都从头相加，要按区间长度重复工作。前缀和（Prefix Sum）把**从开头到某个边界前**的累积和先存起来，之后一段连续区间只需做一次减法。它适合数组**基本不修改、查询很多**的情形。

定义 `P[i] = a[0]+...+a[i-1]`，即前 `i` 项之和。特别地 `P[0]=0`，它代表空前缀，不是数组第 0 项。对长度为 `n` 的数组，`P` 有 `n+1` 项。

| 边界 i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| P[i] | 0 | 2 | 1 | 4 | 8 | 6 |

构造时从左到右用 `P[i+1]=P[i]+a[i]`。例如 `P[2]=2+(-1)=1`；负数完全合法，前缀值不一定递增。

## 两段前缀相减

本课区间统一为半开 `[L,R)`，包含下标 `L` 到 `R-1`，允许 `0≤L≤R≤n`。由于 `P[R]` 是前 `R` 项之和，而 `P[L]` 是前 `L` 项之和，相减后前 `L` 项抵消，剩下正好是 `[L,R)` 的和。

例如 `[1,4)` 对应 `-1+3+4=6`；查询只算 `P[4]-P[1]=8-2=6`。空区间 `[3,3)` 为 `P[3]-P[3]=0`。整个数组 `[0,5)` 为 `P[5]-P[0]=6`。在实验里先点原数组元素设左边界，再点下方边界设右边界，也可用两个滑块精确调节。

**别把右端当成最后一个元素下标。** 如果题目给的是闭区间 `[L,R]`，先转成半开 `[L,R+1)`，答案才是 `P[R+1]-P[L]`。例如闭区间 `[1,3]` 与本课 `[1,4)` 是同一段。

## 面试回答

前缀和把 `P[i]` 定义为前 `i` 个元素的和，以 `P[0]=0` 起步、逐项累加，预处理时间和空间都是 `O(n)`。之后静态数组的半开区间 `[L,R)` 求和为 `P[R]-P[L]`，单次 `O(1)`，负数也适用。若频繁修改原数组某个值，它之后的多个前缀值都要跟着改变，单次更新最坏 `O(n)`；这类“更新和查询都很多”的题应考虑树状数组或线段树，而不是继续声称前缀和同时支持两者 `O(1)`。

## 比较三种操作成本

| 方法 | 预处理 | 一次求和 | 修改一个值 |
| --- | --- | --- | --- |
| 每次现算 | `O(1)` | `O(R-L)` | `O(1)` |
| 静态前缀和 | `O(n)` | `O(1)` | 最坏 `O(n)` |
| 树状数组或线段树 | 通常 `O(n)` 或 `O(n log n)`，视实现 | `O(log n)` | `O(log n)` |

最后一行只作选型对照；两种树的构造方式、支持的操作和边界应在各自课程里学习，不能由前缀和公式直接推出。

## 多语言示例

同一输入 `a=[2,-1,3,4,-2]`、查询 `[1,4)`，预期输出 `6`。下面都以 `P[0]=0` 构造，调用方保证 `0≤L≤R≤n` 且累加结果可由所用整数类型表示。

### C

```c
#include <stdio.h>

int main(void) {
    const long long a[] = {2, -1, 3, 4, -2};
    long long prefix[6] = {0};
    for (int i = 0; i < 5; ++i) prefix[i + 1] = prefix[i] + a[i];
    printf("%lld\n", prefix[4] - prefix[1]);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<long long> a{2, -1, 3, 4, -2};
    std::vector<long long> prefix(a.size() + 1, 0);
    for (std::size_t i = 0; i < a.size(); ++i) prefix[i + 1] = prefix[i] + a[i];
    std::cout << prefix[4] - prefix[1] << '\n';
}
```

### Python 3

```python
a = [2, -1, 3, 4, -2]
prefix = [0]
for value in a:
    prefix.append(prefix[-1] + value)
left, right = 1, 4
print(prefix[right] - prefix[left])  # 6
```

## 易错反例

- 忘记 `P[0]=0`：查询从下标 0 开始的区间时，公式失去统一起点。
- 写成 `P[R]-P[L-1]`：这是把“前 i 项”和另一套“到下标 i 为止”的定义混用了；在 `L=0` 时还会读到非法位置。
- 认为“前缀和一定递增”：本例从 `P[1]=2` 降到 `P[2]=1`，因为第二项是 `-1`。
- 直接修改 `a[1]` 而不更新 `P[2..n]`：之后的区间答案会使用过期数据。

## 选择题

数组 `a=[2,-1,3,4,-2]` 的前缀表如上。半开区间 `[2,5)` 的和是多少？

- A. `P[5]-P[2]=5`
- B. `P[5]-P[2]=6`
- C. `P[4]-P[2]=7`
- D. `P[5]-P[1]=4`

**答案：A。** `P[5]=6`、`P[2]=1`，所以是 `5`，也等于 `3+4-2`。B 算术错误；C、D 选错了边界。
