# 可变别名：一个值被改了两次

## 同一对象可以有多个入口

别名（Aliasing）是两个访问路径指向同一对象；可变性（Mutability）表示该对象的状态能被改变。二者合在一起时，一条路径写入会影响另一条路径之后的读取。以 C11 的顺序执行为例，两个合法 `int *` 可以指向同一个 `int`；这不自动构成错误，但函数若暗自假设它们不同，就可能算错业务结果。[ISO C N1570：指针、赋值与函数调用](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)

## 同一个形参函数，两种调用

```c
#include <stdio.h>

static void bump_both(int *left, int *right) {
    ++*left;
    ++*right;
}

int main(void) {
    int x = 0;
    bump_both(&x, &x);
    printf("same=%d\n", x);

    int a = 0, b = 0;
    bump_both(&a, &b);
    printf("separate=%d,%d\n", a, b);
}
```

预期输出 `same=2`、`separate=1,1`。前次调用两个形参都指向 `x`，两条 `++` 是**先后两个完整语句**，所以 `x:0→1→2`；这不是把两个未排序的副作用写进同一个表达式。后次调用指向不同对象，分别各加一次。这里值很小，不涉及整数溢出。[ISO C N1570：表达式求值与完整表达式](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)

## 逐步推演

### 两个形参接收同一地址

`bump_both(&x,&x)` 让 `left` 与 `right` 都指向 `x`，并未复制出两个独立整数对象。

### 第一条写入

`++*left` 把 `x` 从 0 改为 1。下一语句通过 `right` 读到的已是 1。

### 第二条写入

`++*right` 再把同一个 `x` 从 1 改为 2，因此打印 `same=2`。

### 改为独立对象

传 `&a,&b` 时，`a` 和 `b` 各自从 0 到 1；没有一方读到另一方的变化。

## 与别的概念分界

普通赋值 `int copy=x` 产生独立整数值，后续改 `x` 不会自动改 `copy`；指针赋值或传参复制的是指针值，可能继续别名。**别名不等于并发数据竞争**：本例只有一个线程且语句有先后；若多线程无同步地读写同一对象，还需按语言内存模型单独分析。Rust 的借用规则会限制某些可变别名组合，不能把 C 的权限规则套过去。

## 面试回答

别名表示多条访问路径指向同一对象。若对象可变，一条路径的写入会影响另一条路径之后的读写；传两个指针参数不保证它们一定指向不同对象。设计函数时应明确是否允许别名、更新次序和返回保证。本例两个顺序的 `++` 使同一个 `x` 从 0 到 2；它不是并发数据竞争。

## 选择题

本例 `x=0`，调用 `bump_both(&x,&x)` 后 `x` 是多少？

- A. 0
- B. 1
- C. 2
- D. 未定义行为，因为任何两个指针都不能指向同一个对象

**答案：C。** 两次合法且有序的写入作用于同一对象。B 只算一次，D 把允许的别名误当成一律非法。
