# 正数数组的滑动窗口

## 问题与窗口

给定**正整数**数组 `[2,1,5,2,3,2]` 与目标 `7`，求“元素和至少为 7”的最短**连续**子数组长度。答案是 `2`，对应 `[5,2]`。连续意味着不能只选位置 0、2、5，必须取一个完整下标区间。

滑动窗口（Sliding Window）用半开区间 `[L,R)` 表示当前连续部分：包含 `L`，不包含 `R`，窗口长度是 `R-L`。初始 `L=R=0`、窗口和 `sum=0`。扩张时把 `a[R]` 加入并令 `R++`；收缩时从和里移去 `a[L]` 并令 `L++`。半开写法让空窗口 `[i,i)`、右端恰好到数组长度 `n` 都有一致含义。

## 何时扩张，何时收缩

- `sum < target`：当前窗口不足。因所有数为正，左端继续右移只会让和更小；要尝试右端的新数。
- `sum >= target`：当前窗口已经合格，先用长度 `R-L` 更新最短答案，再移走左端，试探能否更短。
- `R=n` 且 `sum<target`：后面没有新数可加，结束。若一次都没达标，答案为“无解”，不是 0。

这里“最短”与“最长”窗口的收缩条件不能互换。每次达标都要**先记录当前长度，再收缩**；只收缩不记录会丢掉刚刚得到的候选。

## 一次完整的手算

| 操作后 | `[L,R)` | 和 | 更新 |
| --- | --- | --- | --- |
| 依次加入 2、1 | `[0,2)` | 3 | 未达标 |
| 加入 5 | `[0,3)` | 8 | 达标，记长度 3 |
| 移走 2，加入 2 | `[1,4)` | 8 | 达标，长度仍是 3 |
| 移走 1 | `[2,4)` | 7 | 达标，最短改为 2：`[5,2]` |
| 移走 5，依次加入 3、2 | `[3,6)` | 7 | 达标，长度 3；继续收缩后结束 |

表中省去了几个不足 7 的中间窗口，但操作顺序是严格的：每次只改变一个端点，不跳过数组位置。网页实验可以逐次操作，观察和与历史最优值。

## 为什么不是 O(n²)

代码可能有一个 `for` 加内层 `while`，但 `R` 最多从 0 增到 `n`，`L` 也最多从 0 增到 `n`；每个端点都**只向右走**，总移动次数不超过 `2n`。因此时间 `O(n)`，除保存输入外额外空间 `O(1)`。不能单凭“嵌套循环”判断为 `O(n²)`。

正数前提不可省。把数组改成 `[1,-1,3]`、目标 `3`：窗口直到包含三项才首次达标，记录长度 3；按上述规则移走左端 1 后和变成 2，于是结束，却漏掉最后单独的 `[3]`，正确最短长度是 1。负数让“移走左端使和下降”的单调性失效。全非负数组可作相应适配；本课统一要求严格正数且目标为正数，以免空窗口也被视为达标。

## 面试回答

对正整数数组求和至少为目标的最短连续子数组，可维护 `[L,R)`、当前和与最优长度：不足目标则扩张右端，达标就记录长度并收缩左端，直到右端到末尾且当前和不足。正数保证收缩后和下降，因此不会漏掉更短窗口；两端各最多走 `n` 步，时间 `O(n)`、额外空间 `O(1)`。有负数时这套单调规则不成立，不能直接套用。

## 多语言示例

以下独立程序都求 `[2,1,5,2,3,2]`、目标 `7` 的最短长度，预期输出 `2`；若不存在达标区间则输出 `0`，这是代码的返回约定，不表示空区间达标。输入保证所有数与目标均为正，且和不超出所用整数类型。

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int minLength(const std::vector<int>& a, long long target) {
    int left = 0, best = static_cast<int>(a.size()) + 1;
    long long sum = 0;
    for (int right = 0; right < static_cast<int>(a.size()); ++right) {
        sum += a[right];
        while (sum >= target) {
            best = std::min(best, right - left + 1);
            sum -= a[left++];
        }
    }
    return best == static_cast<int>(a.size()) + 1 ? 0 : best;
}

int main() { std::cout << minLength({2, 1, 5, 2, 3, 2}, 7) << '\n'; }
```

### Python 3

```python
def min_length(a, target):
    left = 0
    total = 0
    best = len(a) + 1
    for right, value in enumerate(a):
        total += value
        while total >= target:
            best = min(best, right - left + 1)
            total -= a[left]
            left += 1
    return 0 if best == len(a) + 1 else best

print(min_length([2, 1, 5, 2, 3, 2], 7))  # 2
```

两段代码把 `right` 当“刚刚纳入的最后一个下标”，所以长度写作 `right-left+1`；实验把 `R` 当“不包含的右边界”，长度写作 `R-L`。表达不同，区间是同一段。

## 常见误区与练习

- 目标改成 `20` 时，整数组和只有 `15`，应返回无解；不能默认必有结果。
- `[7]`、目标 `7` 的最短长度是 1；空数组无解。
- 问“长度最长且和不超过目标”是另一种问题，更新答案的条件与时机需重推。

## 选择题

在本课正整数数组的算法中，为什么内层反复收缩不会令总体时间变为 `O(n²)`？

- A. 因为内层循环至多执行一次
- B. 因为左右端点均只向右移动，每个至多 `n` 次
- C. 因为数组元素必须互不相同
- D. 因为目标是常数

**答案：B。** 内层可以在某一轮连续执行多次，但这些移动不会在以后重做。A、C、D 均不是复杂度成立的理由。
