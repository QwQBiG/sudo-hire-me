# 连接池究竟复用了什么

## 为什么需要池

建立数据库连接可能包含网络、认证和会话初始化成本；**连接池**（Connection Pool）预先创建或按需保留一组连接，应用请求借用，工作结束后归还，以减少反复创建和控制并发连接数。这里是**应用侧固定容量池**的教学模型：容量 2，物理连接为 C1、C2。同一条物理连接在同一时刻只借给一个任务，不是让多个任务并发共享同一会话。[PgBouncer：Features](https://www.pgbouncer.org/features.html)

## 逐步推演

### A 与 B 借走两条连接

A 得到 C1，B 得到 C2，池内空闲数 0、借出数 2。它们可以各自在自己的连接上运行事务。

### C 请求时先等待

第三个请求 C 不会凭空获得 C3；按本模型先进入等待队列，直到连接归还或等待超时。池容量为 2，不等于数据库只能承载 2 个连接：别的应用实例可能也开池，数据库总限制要一起计算。

### A 结束并归还，C 获得 C1

A 提交或回滚未完成事务，并按池约定清理会话状态后归还 C1；C 随后借到 C1。若 A 留下未提交事务、临时设置或会话变量，C 可能继承意外状态；不同驱动和池对重置的保障不一样，应验证实际配置。[PgBouncer：Pooling Modes](https://www.pgbouncer.org/features.html)

## 面试回答

连接池复用数据库连接，减少建连开销并给并发连接设上限。容量 2 且两条都借出时，新请求需要排队、超时或按配置处理；归还前必须正确结束事务并清理连接状态，不能让两个请求同时使用同一会话。池大小要考虑应用实例总数与数据库连接上限。应用侧连接池、PgBouncer 的会话池和事务池并不完全一样，后者对会话级特性有额外限制。

## 常见误区

- **“池大小 2 表示只有两个用户能登录。”** 它限制的是同时占用的连接，不是登录用户总数。
- **“归还连接就是关闭物理连接。”** 通常保留连接供下一请求复用。
- **“任何会话状态都能安全跨任务保留。”** 事务与会话状态泄漏会影响下一个借用者。

## 选择题

本课池容量为 2，A、B 正占用 C1、C2，C 此时申请连接。按模型应怎样？

- A. 让 C 与 A 同时写 C1
- B. 必须销毁 C2
- C. C 等待归还或直到超时
- D. 自动把容量永久改成 3

**答案：C。** 两条连接均已借出，新申请先排队或按池配置超时。
