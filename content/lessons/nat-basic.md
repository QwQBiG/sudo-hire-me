# NAT 怎样让多台主机共用一个公网地址

## 先分清“改地址”和“连端口一起改”

网络地址转换（Network Address Translation，NAT）在边界设备上改写经过的数据包地址。传统的**基本 NAT**（Basic NAT）主要把私有 IP 映射到外部 IP；小型网络常见的是**网络地址与端口转换**（Network Address Port Translation，NAPT），把源 IP 与 TCP/UDP 源端口一起映射，使多台内网主机共用一个外部地址。RFC 3022 明确区分两种做法，日常口语常把后者也简称 NAT。[RFC 3022：Traditional NAT](https://www.rfc-editor.org/rfc/rfc3022.html)

设客户端 A 为 `192.168.1.10:50000`，B 为 `192.168.1.11:50000`，两者都要访问服务器 `198.51.100.20:443`。边界设备外部地址为 `203.0.113.5`。`192.168.1.0/24` 取自私有地址范围；`198.51.100.0/24` 和 `203.0.113.0/24` 是仅用于文档示例的地址块，不应理解成真实公网服务。[RFC 1918：Private Address Space](https://www.rfc-editor.org/rfc/rfc1918.html) · [RFC 5737：Documentation Addresses](https://www.rfc-editor.org/rfc/rfc5737.html)

## 逐步推演

### A 的出站包建立第一条映射

A 原包是 `192.168.1.10:50000 → 198.51.100.20:443`。假设网关为它选择外部源端口 `40001`，转发出去的包成为 `203.0.113.5:40001 → 198.51.100.20:443`。服务器看到的是网关的外部地址与映射端口；本例用 `40001` 只是演示，实际设备不保证按这个数字分配。

### B 同源端口也能建立另一条映射

B 原包是 `192.168.1.11:50000 → 198.51.100.20:443`。假设网关选择另一个外部端口 `40002`，映射表此时可简写为：

| 内部源 | 转换后的外部源 |
| --- | --- |
| `192.168.1.10:50000` | `203.0.113.5:40001` |
| `192.168.1.11:50000` | `203.0.113.5:40002` |

两台机器的内部源端口碰巧相同，却不造成冲突；映射后的外部端点不同。实际映射策略还可能结合目的地址和协议，不要把这张简表当成所有 NAT 的精确键结构。[RFC 3022：Overview of NAPT](https://www.rfc-editor.org/rfc/rfc3022.html)

### 回包查映射，送回正确的内部主机

服务器回给 `203.0.113.5:40002` 的包到达网关；网关在对应会话的映射中找到 B，把目标改为 `192.168.1.11:50000` 后转发。回给 `40001` 的包则去 A。若外部主机无缘无故发给 `203.0.113.5:49999`，而网关没有相应映射或静态端口转发规则，就不能凭这一个公网地址推断应交给 A 还是 B；具体处理依设备策略。[RFC 3022：Translation Phases](https://www.rfc-editor.org/rfc/rfc3022.html)

## NAT 不等于防火墙

NAPT 使共享公网地址成为可能，也会改变端到端可达性；外部主动连接内网服务通常需要静态映射、端口转发或其他穿透机制。**地址转换本身不是安全策略的定义**：设备常同时部署过滤规则，但不能因为“用了 NAT”就认为所有流量都已正确过滤。应用协议若把地址写进载荷，或需要端到端连接，也可能受转换影响。[RFC 3022：NAT Limitations](https://www.rfc-editor.org/rfc/rfc3022.html)

## 面试回答

NAT 在网络边界改写地址；常见的 NAPT 还改写 TCP/UDP 端口，使多个私有地址的会话共用一个外部 IP。出站时建立映射，例如 A 的 `192.168.1.10:50000` 对应公网 `203.0.113.5:40001`；回包按会话映射还原并送回 A。没有匹配映射或显式转发规则的入站包不能仅凭公网地址确定内网目标。NAT 不等于防火墙，具体映射与过滤取决于实现和配置。

## 常见误区

- **“NAT 只改 IP，不改端口。”** 基本 NAT 与 NAPT 不同，家用共享公网地址常靠后者。
- **“两台内网机器源端口相同就无法同时上网。”** 网关可分配不同外部端口。
- **“NAT 自动提供完整安全保护。”** 过滤与地址转换是不同职责。

## 选择题

按本课映射表，服务器发往 `203.0.113.5:40002` 的回包应该转给谁？

- A. `192.168.1.10:50000`
- B. `192.168.1.11:50000`
- C. 同时广播给 A 和 B。
- D. 因两台机器的内部端口相同，必然无法转发。

**答案：B。** `40002` 在示例表中对应 B；网关按会话映射还原，而不是只比较两台机器的内部端口。
