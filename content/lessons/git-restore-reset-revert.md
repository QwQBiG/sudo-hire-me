# 说“撤销”之前，先问改动在哪里

## 三种名字不是同一个按钮

工作区是正在编辑的文件，暂存区（Index）记录下一次提交准备包含的内容，提交历史由提交对象和分支指针组成。`git restore` 主要把某个文件在工作区或暂存区恢复为指定来源；`git reset` 可移动当前分支指针，也能调整暂存区；`git revert` 为某个已存在提交的效果创建**新的反向提交**。它们的影响范围不同，不能因为都叫“撤销”就互换。[Git 官方命令总览](https://git-scm.com/docs/git)、[git-revert](https://git-scm.com/docs/git-revert)

决定操作前先确认两件事：改动处于**未提交、已暂存、已提交未共享、已共享**中的哪一步？你要保留内容继续改，还是明确要丢弃它？若回答不清，就先看状态和差异，不运行会覆盖文件的命令。

## 逐步推演

### 第一步：改动只在工作区

你修改了 `config.txt`，尚未暂存。此时 `HEAD` 与暂存区仍是旧内容，只有工作区有新内容。若只是写错一行，最小动作是编辑那一行；若使用恢复工作区文件的操作，它可能**丢弃该文件未提交的改动**。在没有确认改动确实不要之前，不把恢复命令当作无害的“撤销按钮”。

| 位置 | 旧内容 | 新内容 |
| --- | --- | --- |
| `HEAD` 提交 | 有 | 无 |
| 暂存区 | 有 | 无 |
| 工作区 | 无 | 有 |

### 第二步：文件已暂存，但还没有提交

执行暂存后，暂存区和工作区都可含新内容。若只是想把文件从“下次提交候选”移出，`git restore --staged config.txt` 调整的是**暂存区**，通常保留工作区编辑；它不是“把刚写的代码删掉”。仍要检查状态，因为同一文件可能还有暂存后的进一步编辑，暂存区与工作区的内容未必相同。[Git 文档：git-restore](https://git-scm.com/docs/git-restore)

### 第三步：错误已成为本地提交

如果提交尚未共享，可以考虑修正后追加提交，或在确认协作约定与改写影响后整理本地历史。`git reset` 移动分支指针的不同模式会对暂存区、工作区造成不同影响；其中强制丢弃工作区内容的模式尤其危险。面试时不应只背一个命令，而应说明要不要保留文件内容、要不要保留提交记录，以及有没有其他人依赖这些提交。[Git 文档：git-reset](https://git-scm.com/docs/git-reset)

### 第四步：错误提交已经共享

若错误提交已被推送且其他人可能基于它工作，通常优先考虑 `git revert <commit>`：它新增一个提交抵消目标提交带来的改动，保留历史可追踪性。反向应用也可能与后续改动冲突，需要人工处理；revert 不保证业务行为自动正确。它与把分支指针移回去、改写公共历史不是同一回事。[Git 文档：git-revert](https://git-scm.com/docs/git-revert)

若目标是恢复线上服务，仅有代码历史的 revert 还不够：还要确认构建、部署、数据库迁移与用户数据的状态。不能把“代码反向提交已生成”说成“所有影响已撤销”。

## 面试回答

我先看改动的位置和是否已共享。工作区错误要确认是否真的要丢掉文件修改；已暂存但未提交，可只取消暂存并保留工作区内容；本地未共享提交可以在理解影响后整理历史；已共享的错误提交通常用 revert 新增反向提交，而不是随意改写公共历史。`restore`、`reset`、`revert` 作用在不同层次，实际操作前还要检查状态、差异与数据风险。

## 为什么“撤销成功”还要验证

命令退出成功只表明版本控制操作完成，未证明程序恢复正确。要检查最终差异、运行相关测试，并确认部署目标版本；有外部副作用的改动，如数据库写入或已发送消息，也不一定能靠代码回退逆转。

## 常见误区

- **“取消暂存等于删除刚写的代码。”** 调整暂存区与丢弃工作区是不同操作。
- **“revert 会把原提交从历史中删除。”** 它通常新增反向提交。
- **“reset 的所有模式都一样安全。”** 不同模式影响工作区和暂存区不同。
- **“Git 操作成功就表示线上状态恢复。”** 部署和数据副作用还需单独核查。

## 选择题

某文件已暂存但未提交，你想把它移出本次提交，同时保留工作区写好的内容。哪种思路最合适？

- A. 优先只取消该文件的暂存，再检查工作区差异。
- B. 不检查就强制清空整个工作区。
- C. 对一个尚不存在的提交执行 revert。
- D. 改写已经共享的主分支历史。

**答案：A。** 目标只涉及暂存区，应让工作区改动继续保留；B、C、D 都没有对应当前状态与目标。
