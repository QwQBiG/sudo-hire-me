# C 字符串：第一个零字节在哪里

## 字符数组不自动携带长度

C 风格字符串（Null-Terminated Byte String）在字节序列中以值为零的字节 `\0` 作为终止标记。`strlen` 从起点向后查找**第一个**零字节，返回之前的字节数，不包含终止字节。数组容量由数组类型或额外参数提供；仅凭 `char *` 指针不知道可安全扫描的最大范围。[ISO C N1570：字符串与 `strlen`](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)

本课用单字节 ASCII 文本 `Cat`，避免把 UTF-8 多字节文本里的“字符数”与这里的**字节计数**混淆。

## 从五格数组演算

```c
char data[5] = {'C', 'a', 't', '\0', 'X'};
```

| 下标 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 字节 | `C` | `a` | `t` | `\0` | `X` |

扫描从 0 开始依次看到 C、a、t，在下标 3 遇到 NUL 就停，因此 `strlen(data)` 为 3。`X` 确实占据数组第 4 格，但不是这个字符串的一部分；`sizeof data` 在该数组仍可见的作用域中为 5。两者回答的是不同问题：前者扫描到第一个终止符，后者是整个数组对象的字节数。

## 再看字面量自动补的字节

```c
char word[] = "Cat";
```

编译器为 `word` 提供四格：`C`、`a`、`t`、`\0`。因此 `sizeof word` 为 4、`strlen(word)` 为 3。若把 `word` 作为 `char *` 函数形参传入，形参只有指针，不再保有调用方数组的完整大小信息；在函数里对该形参 `sizeof` 得到的是指针对象大小，**不是**原数组容量。[ISO C N1570：数组形参调整与 `sizeof`](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)

## 少一个终止符会怎样

```c
char raw[3] = {'C', 'a', 't'};
```

`raw` 有三个字符字节，却没有 NUL。把它交给期望有效 C 字符串的 `strlen(raw)`，扫描会继续越过数组范围寻找零字节，程序不满足调用前提，**不能预测固定返回值或保证立刻崩溃**。本课网页实验只在已知的数组范围内做安全扫描：若范围内没有零字节，就报告“未在缓冲区内终止”，不会模拟越界读取。

同理，容量为 4 的数组容得下 `"Cat"` 的三个文本字节加一个 NUL；若想存 `"Cats"`，至少需要 5 字节。用 `strcpy` 等接口时必须让目标容量足够；更安全的设计还要明确最大长度和拷贝结果，不能单靠函数名保证安全。[ISO C N1570：`strcpy` 契约](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)

## 面试回答

C 字符串是从起点到首个 `\0` 之前的一串字节；`strlen` 返回终止符之前的字节数，`sizeof` 对当前数组对象给出整个数组占用的字节数。`char word[]="Cat"` 有四字节，长度是三；`{'C','a','t','\0','X'}` 容量五、字符串长度仍三。没有可达的零终止符时不能安全调用要求 C 字符串的函数；传入 `char *` 后也不会自动携带数组容量。UTF-8 文本里的多字节字符又使 `strlen` 与用户感知字符数进一步分离。

## 常见错误

- **“`strlen` 包含 `\0`。”** 它只数终止符前的字节。
- **“数组有五格，字符串一定长五。”** 首个 NUL 在下标 3，后面的 X 不属于该字符串。
- **“`char raw[3]={'C','a','t'}` 可安全传给 `strlen`。”** 缺少终止符，不满足函数前提。
- **“把数组传入函数后 `sizeof` 还能得到原容量。”** 数组形参调整为指针形参。

## 选择题

在 C 中，`char data[5]={'C','a','t','\0','X'};`，`strlen(data)` 与 `sizeof data` 分别是多少？

- A. 3 和 5
- B. 4 和 5
- C. 5 和 5
- D. 3 和 3

**答案：A。** 首个零字节在下标 3，前面有三个文本字节；整个数组占五字节。B 把终止符计入 `strlen`，C 忽略首个 NUL，D 把数组大小当成字符串长度。
